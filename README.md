# Forest 陪伴助手

一个用于 AstrBot 的 Forest 专注森林贴心陪伴插件，提供早安晚安通知、晚安车、打卡统计、树种推送、AI 智能回复等全方位陪伴功能。

## 功能特性

### 🌅 早安晚安通知
- 早安打卡提醒（可配置时间和日期）
- 晚安休息提醒
- 晚安车发车通知（晚安通知前一小时）
- 周统计排行榜自动推送
- 每周学习目标讨论推送

### 🔑 房间密钥提取
- 自动检测 Forest 房间邀请消息格式 `输入我的房间密钥：XXXXXX，和我一起`
- 自动提取房间密钥并发送自定义格式回复
- 支持群聊白名单/黑名单过滤
- 支持响应频率限制（限流）

### 📅 每日打卡系统
- 群成员发送"打卡"即可完成每日打卡
- 自动统计本周打卡天数
- 支持查询个人打卡记录
- 管理员可查看周排行榜

### 🌲 树种推送系统
- 早安通知自动附带每日树种介绍和图片
- 164 个树种数据，随机推送，遍历完自动重置
- 支持关键词或 @机器人 查询树种信息
- AI 查询树种自动附带图片

### 🤖 AI 智能回复
- 关键词唤起 AI 回复（如"果果"）
- 支持 @机器人 触发回复
- AI 可查询用户打卡记录和树种信息
- 独立的关键词限流配置

### 💬 固定回复规则
- 配置关键词触发固定回复
- 例如：发送"安装包"自动回复官方下载链接

### 👋 早安晚安自动回复
- 检测群成员发送的早安/晚安问候
- 只在配置的时间段内触发回复
- 早安触发词：早安、早上好、早、早啊、早早早、早呀、早哟、早安呀
- 晚安触发词：晚安、晚上好、晚、晚啦、晚安呀、晚安哟、睡啦、安安、好梦、早点睡
- 多条回复模板随机选择

### 🚌 晚安车报名
- @机器人 + "晚安车报名" 即可报名
- 报名时间：18:00-24:00（可配置）
- 支持当 **车主**（司机）或 **乘客**：
  - 当车主：说"我当车主，11点，樱花"
  - 当乘客：说"我当乘客"或"我坐小明的车"（选坐某位车主的车）
  - 没选车主的乘客进入**待定池**
- 支持查询今日报名列表（按车分组展示）
- 支持取消个人报名（车主取消后，其乘客自动落回待定池）
- 一人一晚只能一个身份（车主或乘客）
- **车主到点提醒**：到意向时间（或统一发车时间）在群里 @车主 + 带乘客名单
- **报名提示教程**：每日每群首次报名成功附带精简教程，防止新手不会用
- 报名人数 > 2 人时，发车通知按车逐辆展示乘客名单
- 保留历史记录，支持统计功能

### 🌳 树种当日提醒
- @机器人 说"我要种蓝花楹，有人种就叫我"，即可设置**当日树种提醒**
- 当天群里有人发起该树种房间邀请时，机器人自动 @提醒用户加入
- **只当天生效**：提醒带日期标记，第二天自动失效清理
- 同一天同一用户同一树种只提醒一次，不打扰
- 智能识别多种表达：蹲/等/盯着/有人种就叫我/提醒我 等
- 自动拦截混淆场景：晚安车报名、单纯表达"想种树"、查询树种、"我今天种了"等不会被误判为提醒
- 支持设置多个树种（如"蓝花楹 樱花"）、取消提醒（"取消提醒"）、查询提醒（"我的提醒"）

## 安装

将本插件克隆到 AstrBot 的 `addons/plugins/` 目录下：

```bash
cd addons/plugins/
git clone https://github.com/Auro161/astrbot_plugin_forest_room.git
```

重启 AstrBot 或在管理面板中重载插件。

## 配置

在 AstrBot 管理面板中配置以下选项：

### 基础配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enabled` | bool | `true` | 是否启用插件 |
| `reply_format` | string | `{key}` | 回复格式，`{key}` 为密钥占位符 |
| `whitelist` | list | `[]` | 白名单群号，为空则全部群生效 |
| `blacklist` | list | `[]` | 黑名单群号 |

### 限流配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `rate_limit_enabled` | bool | `true` | 是否启用响应频率限制 |
| `rate_limit_window` | int | `60` | 限流时间窗口（秒） |
| `rate_limit_count` | int | `10` | 时间窗口内最大响应次数 |

### 早安通知配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `morning_notify_enabled` | bool | `true` | 是否启用早安通知 |
| `morning_notify_time` | string | `07:00` | 通知时间（HH:MM 格式） |
| `morning_notify_days` | list | `[1,2,3,4,5,6,0]` | 通知日期（0=周日，1-6=周一至周六） |
| `morning_notify_text` | string | 见配置 | 早安通知文案 |

### 晚安通知配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `night_notify_enabled` | bool | `true` | 是否启用晚安通知 |
| `night_notify_time` | string | `23:00` | 通知时间（HH:MM 格式） |
| `night_notify_days` | list | `[0,1,2,3,4,5,6]` | 通知日期 |
| `night_notify_text` | string | 见配置 | 晚安通知文案 |

### 周统计配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `weekstat_enabled` | bool | `true` | 是否启用周统计推送 |
| `weekstat_day` | int | `1` | 推送日期（1=周一） |
| `weekstat_time` | string | `07:00` | 推送时间 |
| `rank_top_n` | int | `5` | 排行榜显示人数 |

### 学习目标配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `topic_notify_enabled` | bool | `true` | 是否启用学习目标推送 |
| `topic_notify_day` | int | `1` | 推送日期（1=周一） |
| `topic_notify_time` | string | `08:00` | 推送时间 |

### 关键词回复配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `keyword_reply_enabled` | bool | `true` | 是否启用关键词 AI 回复 |
| `keywords` | list | `["果果"]` | 触发关键词列表 |
| `keyword_rate_limit_enabled` | bool | `true` | 是否启用关键词限流 |
| `keyword_rate_limit_window` | int | `60` | 限流时间窗口（秒） |
| `keyword_rate_limit_count` | int | `5` | 时间窗口内最大触发次数 |

### 固定回复配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `fixed_reply_enabled` | bool | `true` | 是否启用固定回复 |
| `fixed_reply_rules` | list | 见配置 | 固定回复规则列表 |

### 树种推送配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `tree_notify_enabled` | bool | `true` | 是否在早安通知中附带树种介绍 |

### 早安晚安自动回复配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `greeting_reply_enabled` | bool | `true` | 是否启用早安晚安自动回复 |
| `morning_greeting_start` | string | `06:00` | 早安回复开始时间 |
| `morning_greeting_end` | string | `10:00` | 早安回复结束时间 |
| `morning_greeting_replies` | list | 见配置 | 早安回复内容列表（随机选择） |
| `night_greeting_start` | string | `21:00` | 晚安回复开始时间 |
| `night_greeting_end` | string | `02:00` | 晚安回复结束时间（支持跨天） |
| `night_greeting_replies` | list | 见配置 | 晚安回复内容列表（随机选择） |

### 晚安车发车通知配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `night_bus_notify_enabled` | bool | `true` | 是否启用晚安车发车通知 |
| `night_bus_notify_time` | string | `22:00` | 发车通知时间（车主未填意向时间时的兜底提醒时间） |
| `night_bus_driver_remind_enabled` | bool | `true` | 是否启用车主到点提醒（与发车通知独立开关） |

### 晚安车报名配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `night_bus_enabled` | bool | `true` | 是否启用晚安车报名 |
| `night_bus_start` | string | `18:00` | 报名开始时间 |
| `night_bus_end` | string | `00:00` | 报名结束时间 |
| `night_bus_tree_required` | bool | `false` | 是否强制填写意向树种 |
| `night_bus_tutorial_enabled` | bool | `true` | 是否在每日首次报名时附带精简教程 |
| `night_bus_tutorial_text` | string | 留空 | 教程文案（留空则按当前报名时段自动生成） |

### 树种当日提醒配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `tree_alert_enabled` | bool | `true` | 是否启用树种当日提醒 |
| `tree_alert_template` | string | 留空 | 触发提醒时的文案模板，`{tree}` 为树种名占位；留空使用默认文案 |

## 使用示例

### 房间密钥提取

当群成员分享 Forest 房间邀请时：

```
用户：输入我的房间密钥：ABC123，和我一起种树吧！
机器人：ABC123
```

### 打卡功能

用户：我的打卡
机器人：📅 本周已打卡 3 天
```

```

```

### 树种当日提醒

```
用户：@机器人 我要种蓝花楹，有人种就叫我
机器人：✅ 已记住：今天有人发起「蓝花楹」房间，我会 @你！
（提醒当天有效，不需要了说「取消提醒」~）

[当天群里有人发起蓝花楹房间邀请]
机器人：@用户 你等的 蓝花楹 来啦！🌳
有人发起了「蓝花楹」房间邀请，快跟上一起种！

用户：@机器人 蹲一个樱花
机器人：✅ 已记住：今天有人发起「樱花」房间，我会 @你！
（提醒当天有效，不需要了说「取消提醒」~）

用户：@机器人 我的提醒
机器人：📋 你今天的树种提醒（2 条）：
  • 蓝花楹 [⏳ 等待中]
  • 樱花 [✅ 已提醒过]

注意：设置提醒需要 **@机器人** 才会处理；只当天有效，第二天自动失效。混淆场景（如"晚安车报名"、"我想种树"、"蓝花楹是什么树"、"我今天种了蓝花楹"）不会被误判为设置提醒。

## 技术要求

- AstrBot >= 3.0.0
- Python >= 3.8
- 仅支持 aiocqhttp 平台（如 QQ）

## 数据存储

插件使用 SQLite 数据库存储以下数据：
- 用户打卡记录（`checkins` 表）
- 学习主题（`topics` 表）
- 树种推送记录（`pushed_trees` 表）
- 晚安车报名记录（`night_bus_signups` 表）
- 树种当日提醒记录（`tree_alerts` 表）

数据库文件位置：`addons/data/astrbot_plugin_forest_room/forest.db`

## 树种数据

树种数据位于 `tree/` 目录：
- `tree/tree_names.json` - 树种信息（中英文名、稀有度、描述）
- `tree/mature_trees/` - 树种图片目录

更新树种数据只需：
1. 更新 `tree_names.json` 添加新树种
2. 在 `mature_trees/` 添加对应图片
3. 重启插件或重载即可
